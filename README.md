Descrição do Projeto:

Diabetes é uma doença que afeta muitos indivíduos ao redor do mundo, e há a necessidade de saber os hábitos e as possíveis causas dessa doença, para que um indivíduo saudável possa evitar desenvolvê-la. Para isso, foi extraído um dataset de um estudo sobre relação entre estilo de vida e diabetes, para análise.

Link do dataset original:
https://archive.ics.uci.edu/dataset/891/cdc+diabetes+health+indicators


Instruções de execução:

Criar um notebook no Databricks Free Edition, File - Import, URL: https://raw.githubusercontent.com/joaopilger25/Joao_Diabetes/refs/heads/main/Sistematizacao%20CD2.ipynb, importar, clicar em "Run All".
